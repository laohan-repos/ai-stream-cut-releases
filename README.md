# 剪吧

剪吧的软件下载与版本更新仓库。

**[下载最新版本](https://github.com/laohan-repos/ai-stream-cut-releases/releases/latest)** · [查看版本与更新说明](https://github.com/laohan-repos/ai-stream-cut-releases/releases)

## 选择安装包

| 系统 | 文件名 |
| --- | --- |
| Mac Apple Silicon（M 系列芯片） | `jianba-版本号-mac-arm64.dmg` |
| Mac Intel | `jianba-版本号-mac-x64.dmg` |
| Windows 10 / 11，64 位 | `jianba-版本号-windows-x64-setup.exe` |

Mac 同时提供 ZIP 包。每个版本中的 `SHA256SUMS.txt` 可用于验证安装包的完整性。

在 Releases 页展开 **Assets**，选择对应系统的安装包。

## 安装与升级

安装包自带运行环境，无需另外安装 Node.js、FFmpeg 或数据库。升级前完全退出旧版，再安装并启动新版；已有项目和设置继续保存在本机。

各版本的新增功能、修复内容与连接说明，请查看对应 Release 的更新说明。
